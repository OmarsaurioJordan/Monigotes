# Monigotines

## Tareas

- en ficha de monigote poner estadisticas
- escribir todas las habilidades, redactar

## Habilidades Extra

1. cree una entrada de título y texto en "HabExtra" de la escena "habilidades.tscn"
2. coloque la "Img" de dicha entrada en el "frame" único para esa habilidad extra
3. en "master.gd" agregue entrada a HAB_EXTRA que coincida con el "frame" anterior
4. en "ficha.gd" en init_ficha(), el comentario "habilidades extra" ahí la condición que asocia "habilidades.tscn" con Master.HAB_EXTRA
